# PortfolioHUB — João Pedro Regattieri Bruno

Este repositório contém o portfólio acadêmico e profissional de **João Pedro Regattieri Bruno**, estudante de Ciência da Computação. O projeto foi estruturado seguindo rigorosas diretrizes de Engenharia de Software e Segurança da Informação, validadas pelo **Google GEMINI**.

## 🚀 Estrutura do Ecossistema

O **PortfolioHUB** não é apenas uma página estática, mas um ambiente de demonstração de competências técnicas integradas ao GitHub:

- **Hospedagem:** GitHub Pages com imposição de HTTPS (TLS).
- **Segurança:** Proteção contra *Reverse Tabnabbing* via `rel="noopener noreferrer"`.
- **Interface:** Design responsivo com console de gestão dinâmico (*Painel HUB*).
- **Semântica:** Código validado em HTML5/CSS3 com foco em acessibilidade (ARIA).

## 🛠️ Governança de Código

Para garantir a auditabilidade e o profissionalismo do histórico de desenvolvimento, este projeto adota:

### 1. Padrão de Commits (Conventional Commits)
Todas as mensagens de commit devem seguir o formato semântico:
- `feat`: Quando uma nova funcionalidade ou seção for adicionada.
- `fix`: Quando um erro ou vulnerabilidade for corrigido.
- `docs`: Para alterações exclusivas em documentação.
- `chore`: Para tarefas de manutenção ou configuração.

### 2. Estratégia de Branching (GitHub Flow)
- `main`: Branch de produção, protegida e sempre estável.
- `feature/...`: Branches temporárias para novas implementações, integradas via Pull Request (PR).

## 🛡️ Políticas de Segurança Implementadas

1. **Isolamento de Contexto:** Links externos utilizam diretivas de segurança para prevenir ataques de phishing.
2. **Controle de Acesso (RBAC):** Gestão de identidades configurada no repositório remoto.
3. **Rastreabilidade por Hashing:** Cada modificação gera um identificador único para auditoria (visível no Painel HUB).
